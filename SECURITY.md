# Security policy

Please do not publish security vulnerabilities or private credentials in a public issue.

Report a suspected vulnerability privately to the Hynoe owner or moderation team through the official Hynoe Discord linked from `https://hynoesmp.com/`. Include the affected page, what happened, and the minimum steps needed to reproduce it. Do not include real passwords, tokens, private player information, or destructive proof-of-concept data.

The website never needs a private server, moderation, Turnstile, or hosting token in browser code. If one is ever visible in a page, JavaScript file, repository commit, screenshot, or browser response, treat it as compromised and rotate it immediately.
