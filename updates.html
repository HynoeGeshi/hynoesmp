OCTOBER 7 · HOMES GUI INTEGRATION

Your homes, in one live menu.

The broken /home redirect has been removed. Bare /home and /homes now open the existing Homes inventory menu, while /home <name> retains direct teleport.

You have one starter home plus up to four campaign-earned slots. The creation limit, menu capacity, and campaign Perks screen now agree. Handbook and Campaign buttons lead to that same menu.

The change runs on the server using the existing SGui library. It adds no new client-mod requirement. Saved homes, the five-second delay, and existing teleport rules are preserved. Capacity tests and server startup passed; an actual player menu check is still pending.

See home commands and campaign unlocks.

OCTOBER 7 · IN-GAME INTEGRATION REPAIRS

The menus now lead to the same live systems.

The Handbook and Campaign Token buttons open the live Token Vault. The Handbook also opens the seasonal journal, and 28 seasonal buttons now use the event’s existing action dispatcher.

Assistant v1.2.2 repairs ordinary-player command routing while preserving the player context. New /ask answers explain how campaign progress, Fall objectives, Dollars, Tokens, and the Auction House fit together.

The patch also repairs Frostpale growth-stage loot and a chest-enchantment compatibility issue. All reward amounts and claim functions are preserved: the repeatable loyalty reward remains 2 Tokens per 3 hours online.

The server restarted successfully and the post-restart log contained no ERROR entries. Some third-party mod warnings remain under investigation; this is not a claim that every mod or world chunk is error-free.

OCTOBER 7 · VERIFIED SERVER WORK

The Fall event loop is working again.

The Fall v2.5 main loop used a time command that Minecraft 26.2 no longer accepts. That stopped the function from loading. The command has been repaired, the datapacks reloaded, and the seasonal loop successfully executed on the server.

This repair preserves the existing seasonal objectives, rewards, and resource pack. Keep using your current Hynoe SMP client pack.

What was checked

  • All 178 installed mod files were inspected for archive integrity, metadata, and required dependency names.
  • The ten original custom world datapacks were checked; the new integration repair pack is also enabled. Campaign v15.1 and Fall v2.5 remain active.
  • The server answered /ask and invoked the current campaign stage through /next.

Still under investigation

The review also found missing Mythic Upgrades block registrations in older chunks, Alex’s Mobs effect errors, and structure-generation warnings involving C2ME and Towns and Towers. Those mod issues have not been repaired. If you encounter missing blocks, unusual structures, or trouble while exploring, report the location and symptoms in Discord.

See the checked server mod inventory.

October 1: rewards along the way

151 mission rewards

Each tracked campaign requirement gains one-time cash. Together they total $76,150 across all 31 stages. Existing stage payouts remain the larger milestones.

31 stage bundles

Corrected October 8 after checking the live reward functions: stages 1–30 award their themed or utility bundle once. Stage 31 awards its bundle on every successful Ascension; its mission cash remains one-time.

$75 / $150 / $300

Visible normal and modded advancements pay by category: Task, Goal, and Challenge. Internal Hynoe technical advancements do not pay.

Earlier progress counts

The update backtracks completed stages for new mission cash and scans eligible completed advancements once. Reconnecting or rechecking is not intended to pay the same reward again.

Campaign screens that explain themselves

  • Clearer current / required progress across all 31 stages.
  • TURN IN (CONSUMED) means the items are handed over when the complete claim succeeds. HAVE, KEEP, and DO requirements are not consumed.
  • Use the claim buttons in the live quest menus, including Stage 31.
  • An Assistant button on every stage and location guidance for rare-mob objectives.

Use /quests for actual progress, exact requirements, and available rewards.

Less guessing. More playing.

The handbook is a reference when you need it. Start with help or ask a plain-language question. The October 7 console check confirmed that /ask answers server questions and /next invokes the current campaign stage. Player-specific screens still depend on your in-game progress.

/help
Open the simple guide.
/ask <question>
Ask about server systems or finding a mob. Try “/ask where do I find a Farseer”.
/next
Open your current campaign stage.
/quests
Check and claim campaign progress.
/season
Open the seasonal hub.
/tips off / /tips on
Control optional tips that rotate about every five minutes.
/token / /tbal
Open the Token Vault or check your Token balance.
/auction
Open the Auction House.

If you need help with your own progress, open /quests or ask in Discord.
