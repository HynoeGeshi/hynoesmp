HYNOE SMP INSTALLER
NO MODS FOLDER REQUIRED

Install Hynoe SMP the easy way.

Use the Modrinth App to install the Hynoe SMP client pack. You do not need to manually move mods into Minecraft folders or configure Fabric yourself.

FIRST TIME PLAYING? You need the Modrinth App installed before the Hynoe SMP pack can be imported. Follow the steps below in order.
01
INSTALL THE LAUNCHER

Get the Modrinth App

If you do not already have Modrinth, install it first. Modrinth handles the correct Minecraft version, Fabric setup, and the Hynoe SMP pack for you.

GET MODRINTH APP ↗
Already have Modrinth? Skip straight to Step 2.
02
GET THE HYNOE PACK

Download Hynoe SMP

Download the official Hynoe SMP Modrinth pack. Save it somewhere easy to find, such as your Downloads folder.

Hynoe_SMP_Modrinth.mrpack
↓ DOWNLOAD HYNOE SMP
Important: Do not try to open the file with Notepad. Import it from inside the Modrinth App in the next step.
03
IMPORT THE PACK

Open it inside Modrinth

Open the Modrinth App. Create a new instance and choose the option to import from a file. Select Hynoe_SMP_Modrinth.mrpack from your Downloads folder.

Quick path:
Modrinth App → + Create Instance → From File / Import → choose the Hynoe SMP .mrpack.
04
ENTER THE WORLD

Launch and play

Once the import finishes, open the new Hynoe SMP instance in Modrinth and press Play. The pack is now installed — no manual mods-folder setup required.

WINDOWS TROUBLESHOOTING

“Select an app to open this .mrpack file”?

That does not mean the download is broken. Close that Windows popup, open the Modrinth App, and import the file from inside Modrinth using Step 3 above.
