Data deletion

Most current Hynoe Outpost progress is stored in your own browser. This page separates data you can remove yourself from older server-side records that may require a private request.

1. Remove local Hynoe browser data

Hynoe Outpost progress, game preferences, guide progress, local callsign/player identifier, and similar state may be saved in browser storage such as localStorage.

  1. If you care about current progress, understand that clearing site data may permanently remove the local save from that browser/device.
  2. Open your browser's settings for site data/storage.
  3. Find data for hynoesmp.com.
  4. Choose the browser option to clear/remove that site's stored data.
  5. Reload the site. Local Hynoe Outpost and guide state should start fresh.

Browser menu names differ by browser and device. Clearing all browser data can affect many unrelated sites, so prefer the per-site control when available.

2. Cloud account deletion

Cloud accounts and cloud saves are not live, so there is currently no Hynoe email/cloud account to delete through this website. A self-service account/save deletion path is a required launch condition before Hynoe enables worldwide cloud accounts.

3. Legacy leaderboard records

The current build places global leaderboard uploads on a privacy hold. Older Hynoe Outpost builds may have submitted a random player identifier, callsign, and bounded gameplay metrics to the legacy leaderboard service before that hold.

If you want Hynoe to review whether a legacy leaderboard record is associated with you, or request deletion where Hynoe can identify and control that record, use the official Hynoe Discord linked from hynoesmp.com and ask for a private conversation with the Hynoe owner or moderation team.

Do not post your player ID, email address, legal name, or other private identifier in a public Discord channel. Ask for a private contact first. Hynoe may request only the information reasonably necessary to locate or verify the record.

4. Other privacy-rights requests

Depending on where you live, you may have rights concerning personal data that cannot be handled solely by clearing browser storage. Use the same private contact route for an access, correction, deletion, restriction/objection, or portability request involving Hynoe-controlled server-side data.

Hynoe will need to verify requests enough to avoid giving one person's data to another person. If a requested record is held only by an independent third-party service rather than Hynoe, Hynoe may direct you to that provider's rights process where appropriate.

5. Security reports are different

If you found a vulnerability or exposed credential, do not put exploit details, passwords, tokens, or private player information into a public issue or public Discord channel. Report it privately to the Hynoe owner/moderation team.
